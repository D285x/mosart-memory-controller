## 2. AXI4-Lite wrapper (Icarus)

`rtl/axil_mem_ctrl.v` with `tb/tb_axil_mem_ctrl.v`. The wrapper maps the configuration registers and the memory words into an AXI4-Lite address space, returns OKAY, SLVERR (rejected or disabled controller) or DECERR (unmapped or misaligned address) and serves one transaction at a time. The testbench checks register reset values, every word at every wait-state setting, a constant wrapper latency offset (response latency equals offset plus N, offset 5 cycles at N = 0), error responses, STATUS flags, write protect, disabled operation, back-pressure on B and R, write priority when both channels request in the same cycle, and a 2,000 operation random run against a model.

## 3. Mutation analysis (Icarus, SBY, Yosys SAT)

Scripts: `mutation/mutate.py`, `mutation/mutlib.py`, `mutation/report.py`. Full tables: `results/mutation_results.md`, `results/mutation_results.csv`.

| Measure | Killed | Total | Score |
|---|---|---|---|
| 172 mutants, first testbench | 154 | 172 | 89.5 percent |
| 172 mutants, strengthened testbench | 159 | 172 | 92.4 percent |
| Excluding 13 mutants shown equivalent | 159 | 159 | 100 percent |
| Formal property checks, excluding equivalent mutants | 153 | 159 | 96.2 percent |

- The 172 mutants are 23 hand-written and 149 generated by nine operator classes (relational, logical, negation, constant, arithmetic, bit index, statement deletion, stuck-at, state target). None failed to compile.
- Of the 18 mutants that survived the first testbench, 13 are equivalent to the original within a 24-cycle SAT miter (DATA_W 2, ADDR_W 3). They change reset values of registers that are reloaded before use, the encoding of the unused ERROR state, unreachable default branches, and a comparison that is identical at its boundary.
- The other 5 survivors exposed two missing specification checks: read data must stay constant between reads, and the memory contents and read data must be zero at power-up. Directed tests D13 and D1b close both gaps. Functional coverage was already 47 of 47 when these gaps existed.
- Earlier study with the 19 hand-written mutants only: 16 of 19 detected, then 19 of 19 after tests D10, D11 and D12.
- Formal and simulation kill sets: simulation kills every non-equivalent mutant. The 6 mutants that the formal checks miss (M21, M22, M23, G143, G144, G145) are in the memory array, its power-up state and the top-level wiring, which the block-level properties and the shallow end-to-end check do not reach. Formal kills two output-equivalent mutants (G053, G054) through an internal-state property, which simulation cannot see.
- The miter cannot judge mutants of the memory array's power-up value, because both copies start from zero. They are marked INITIAL_STATE and were judged by simulation.

## 4. Formal verification (SBY)

Property files: `formal/formal_fsm.sv`, `formal/formal_cfg.sv`, `formal/formal_top.sv`. Inputs are free, so every host and configuration behaviour is covered within the stated depth.

| Block | Task | Result | Meaning |
|---|---|---|---|
| FSM | prove | PASS | All FSM properties hold for all time (k-induction, depth 20) |
| FSM | bmc | PASS | Same properties for every input sequence up to 30 cycles |
| FSM | latency | PASS | With constant configuration an accepted access completes in exactly 2 + N cycles, a rejected one in 1 cycle |
| FSM | cover | PASS | Zero and seven wait states, both strobes, all rejection types and overrun are reachable |
| Config registers | bmc | PASS | Registers, read-back, reset values, write isolation and sticky bits match the register map (25 cycles) |
| Config registers | cover | PASS | Saturation, write-one-to-clear and event with clear are reachable |
| Top level | cover | PASS | The end-to-end check is reachable |
| Top level | bmc | PASS | Data returned by an accepted read equals the last accepted write to that address (24 cycles, DATA_W 4, ADDR_W 3) |
| Top level | bmc, small | PASS | Same property (24 cycles, DATA_W 2, ADDR_W 2) |

Limits: only the FSM properties are proven for all time. The configuration register properties and the top-level consistency property are bounded checks. The top-level check is slow in Z3 (minutes to tens of minutes), so the mutation flow uses a 12-cycle version.

## 5. Latency measurement design (Icarus)

`board/tb_edge_latency.v`: 160 checks, 0 errors. The sweep completes, every stored measurement equals L = 2 + N and T = 16 x (3 + N), the seven-segment display decodes correctly for all 32 combinations, an injected fault (wait states forced to zero) is reported as FAIL, and the centre button restarts the sweep.

## 6. Timing model (calculation)

`tools/wait_states.py` maps a device access time and a clock to the wait-state setting, N = ceil(tACC / Tclk) - 1, with N limited to 7, and reports latency and throughput. The table is in `results/timing_model.md`. It is a model, not a measurement.

## Build run notes (EDGE Artix-7, Vivado 2025.2)
- xsim: all benches PASS. The core bench reports 2749 checks in xsim and 3356 in Icarus because the two simulators draw different random streams; both pass.
- Latency design: 159 LUTs, 136 registers, WNS +11.154 ns at 50 MHz, estimated Fmax 113.0 MHz, 0.081 W. On-board latency measurement performed: 32 of 32 readings (L_r, L_w, T, T/16 for N = 0 to 7) match L = 2 + N and T = 16 x (3 + N).
- Clock sweep: 33 of 40 runs completed; all met timing up to 333 MHz, none at 400 MHz.
