# Mutation analysis: uart

Mutants: 13 hand-written (class DIR) and 97 generated by operator, in `rtl/uart_tx.v`, `rtl/uart_rx.v`, `rtl/uart.v`.

- Simulation v1: `tb/tb_uart_v1.v` (frozen before any mutant was run).
- Simulation v2: `tb/tb_uart_v2.v` (v1 plus the tests added after analysing the v1 survivors).
- Formal: `formal/uart.sby` task bmc; `formal/uart.sby` task deep.
- Equivalence: port-level miter `equiv/port_miter.sv` against the original for every v1 survivor (depth 80 with PRESCALE = 1, depth 80 with PRESCALE = 2).
- Specification equivalence: for miter-distinguishable survivors, `equiv/spec_miter.sv` compares only the specified behaviour (depth 80); power-up mutants use `equiv/spec_miter_powerup.sv`.

Argued equivalent (tool-distinguishable, but within the specification):

- G008 (assignment to s_axis_tready_reg deleted): reset no longer clears s_axis_tready: the only difference is s_axis_tready high while reset is applied or in the first cycle after it, when the transmitter is idle; AXI-Stream allows tready in any cycle and no transfer takes place during reset.
- G030 (> to >=): the stop bit ends after exactly one bit period (8 x prescale cycles) instead of one bit period plus one cycle; both meet the 8N1 framing, only the idle time before the next frame differs by one cycle.
